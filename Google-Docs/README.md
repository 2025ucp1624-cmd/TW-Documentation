
# Google Docs - Online Document Creation and Collaboration

## What I Learned

Google Docs is a cloud-based word processor that allows users to create, edit, store, and share documents online. Multiple people can work on the same document at the same time.

It is useful for creating reports, assignments, project documents, and collaborating with others.

# Important Features

 Real-time collaboration | Allows multiple users to edit a document together |
 Comments | Helps users give feedback |
 Suggesting mode | Shows proposed changes without directly replacing the original text |
 Version history | Allows users to view and restore earlier versions |
 Templates | Provides ready-made document layouts |
 Sharing permissions | Controls who can view, comment, or edit |
 Exporting | Downloads documents in formats such as PDF and DOCX |

## Practical Uses

 Creating college assignments and reports.
 Working on group projects with classmates.
 Reviewing documents using comments and suggestions.
 Sharing documents with different access permissions.
 Tracking changes and restoring previous versions.

## My Understanding

I learned that Google Docs makes document creation and collaboration easier because everything is stored online. Unlike working on separate files, multiple people can edit one document together and see changes in real time.

I also understood the importance of version history and sharing permissions. Version history helps recover previous work, while permissions protect documents by controlling access.


# Technical Writing Documentation

This repository contains the documentation of the topics I learned during my Technical Writing course. It includes notes about different tools and technologies used for creating documents, presentations, code documentation, and version control.

## Topics Covered

[LaTeX](LaTeX/README.md) | Creating and formatting technical documents |
[Beamer](Beamer/README.md) | Creating presentations using LaTeX 
[Doxygen](Doxygen/README.md) | Generating documentation from source code |
[Google Docs](Google-Docs/README.md) | Creating and collaborating on online documents 
[Git](Git/README.md) | Version control and managing code changes 
[GitHub](GitHub/README.md) | Hosting and sharing projects online 

## Purpose

The purpose of this repository is to keep my learning organized in one place and document my understanding of the concepts covered in the course.

Each topic has its own folder containing a README file with explanations, important concepts, commands, and examples.
